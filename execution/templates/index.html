GA4 Data Dictionary

A reference of available engagement metrics and dimensions you can query.

Category Metric / Dimension Description
Dimensionevent_dateThe date the event was logged (YYYYMMDD).
Dimensionevent_timestampThe time (in microseconds, UTC) the event was logged.
Dimensionevent_nameThe name of the event (e.g., session_start, view_item).
Recordevent_paramsArray containing event parameters (key-value pairs) like session_engaged.
Dimensionuser_pseudo_idThe pseudonymous ID representing a unique user (cookie/device ID).
Dimensionuser_idThe logged-in User ID (if tracked).
RecorddeviceDevice attributes (category, OS, browser).
RecordgeoGeographic attributes (country, region, city).
Recordtraffic_sourceTraffic acquisition source, medium, and campaign name.
RecordecommerceTransaction details like purchase_revenue_in_usd, tax, and shipping.
RecorditemsArray of products involved in events, tracking item_name, item_category, price, quantity, etc.
Upper FunnelTotal Unique UsersTotal unique browsers/devices that visited the site.
Upper FunnelTotal SessionsTotal number of individual visits.
Upper FunnelEngaged SessionsSessions where user stayed >10s, converted, or viewed 2+ pages.
Upper FunnelBounce RatePercentage of sessions that ended without meaningful interaction.
Mid FunnelCategory Item ViewsTotal number of times products in a specific category were viewed.
Mid FunnelView-to-Cart RatioRatio of add_to_cart events to view_item events.
Mid FunnelCart Abandonment RatePercentage of users who added an item to cart but did not purchase.
Mid FunnelFunnel Drop-off RatePercentage of users dropping off between sequential stages.
Lower FunnelE-commerce Conv. Rate (ECR)Percentage of all visits that result in a purchase.
