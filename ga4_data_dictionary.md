# GA4 & E-Commerce Metrics Data Dictionary

This document serves as a comprehensive reference for the raw BigQuery GA4 schema and all downstream calculated metrics used by the AI agents.

---

## 1. Raw GA4 BigQuery Schema (Base Columns)

The following columns represent the standard fields available in the `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*` dataset:

| Column Name | Data Type | Description |
|---|---|---|
| `event_date` | STRING | The date the event was logged (YYYYMMDD). |
| `event_timestamp` | INTEGER | The time (in microseconds, UTC) the event was logged. |
| `event_name` | STRING | The name of the event (e.g., `session_start`, `view_item`, `purchase`). |
| `event_params` | RECORD | An array containing event parameters (key-value pairs) like `session_engaged`, `ga_session_id`, `page_title`, etc. |
| `user_pseudo_id` | STRING | The pseudonymous ID representing a unique user (cookie/device ID). |
| `user_id` | STRING | The logged-in User ID (if tracked). |
| `device` | RECORD | Contains device attributes (category, OS, browser, screen resolution). |
| `geo` | RECORD | Contains geographic attributes (country, region, city). |
| `traffic_source` | RECORD | Contains the `source`, `medium`, and `name` (campaign) of the traffic that acquired the user. |
| `ecommerce` | RECORD | Contains transaction details like `purchase_revenue_in_usd`, `transaction_id`, `tax`, and `shipping`. |
| `items` | RECORD | An array of individual items (products) involved in e-commerce events, tracking `item_name`, `item_category`, `price`, `quantity`, etc. |

> [!WARNING] 
> **Event Params Quirk**: `event_params` stores values in strict typed fields (`string_value`, `int_value`, `float_value`, `double_value`). Parameters like `session_engaged` can unpredictably switch between string and int formats, requiring defensive SQL parsing using `COALESCE`.

## 2. Calculated Metrics & Formulas

These metrics are derived dynamically by the **CalculationAgent** and **DataArchitectAgent** to provide strategic business insights.

### General Financials

| Metric | Formula / Calculation | Description |
|---|---|---|
| **Gross Profit** | `SUM(Item Revenue × Item Category Margin Rate)` | The raw profit on goods sold. Margin rates are pulled dynamically from `master_data.yaml` per category. |
| **Contribution Margin** | `Gross Profit - Ad Spend` | The net cash generated by the business after fulfilling product costs and customer acquisition costs. |
| **ROAS (Baseline)** | `Total Revenue / Ad Spend` | Return on Ad Spend. Measures how many dollars of revenue are generated for every $1 spent on a given channel. |
| **CPA (Cost Per Acquisition)**| `Ad Spend / Total Purchases` | The average marketing cost required to drive a single successful transaction. |
| **RPC (Revenue Per Session)**| `Total Revenue / Total Sessions` | Unit economics metric showing the average value generated by each individual site visit. |
| **Net Unit Profit** | `RPC - CPC (Cost Per Click)` | Unit economics metric measuring the profit of acquiring a single click/session. |

### Upper Funnel (Awareness & Acquisition)
Driven by `first_visit` and `session_start` events.

| Metric | Formula / Calculation | Description |
|---|---|---|
| **Total Unique Users** | `COUNT(DISTINCT user_pseudo_id)` | The total number of unique browsers/devices that visited the site. |
| **Total Sessions** | `COUNT(DISTINCT CONCAT(user_pseudo_id, ga_session_id))` | The total number of individual visits. |
| **Engaged Sessions** | Count of sessions with `session_engaged = 1` or a `user_engagement` event. | Sessions where the user stayed >10 seconds, converted, or viewed 2+ pages. |
| **Bounce Rate** | `1 - (Engaged Sessions / Total Sessions)` | The percentage of sessions that ended without meaningful interaction. |
| **Cost Per Engaged Session**| `Ad Spend / Engaged Sessions` | Evaluates traffic quality vs. acquisition cost. |

### Mid Funnel (Consideration & Intent)
Driven by `view_item` and `add_to_cart` events.

| Metric | Formula / Calculation | Description |
|---|---|---|
| **Category Item Views** | `COUNT(view_item)` segmented by category | Total number of times products in a specific category were viewed. |
| **View-to-Cart Ratio** | `Total add_to_cart / Total view_item` | Evaluates product appeal and pricing power. |
| **Cart Abandonment Rate** | `1 - (Total purchase / Total add_to_cart)` | The percentage of users who added an item to their cart but left without buying. |
| **Funnel Drop-off Rate** | `(Users at Start Stage - Users at End Stage) / Users at Start Stage` | Measures the percentage of users dropping off between any two sequential funnel stages (e.g., Session Start to View Item). |

### Lower Funnel (Conversion)
Driven by `begin_checkout` and `purchase` events.

| Metric | Formula / Calculation | Description |
|---|---|---|
| **E-commerce Conv. Rate (ECR)**| `Total purchase / Total Sessions` | The percentage of all visits that result in a purchase. |
| **Average Order Value (AOV)** | `Total Revenue / Total purchase` | The average dollar amount spent per transaction. |
| **Revenue per Active User** | `Total Revenue / Total Unique Users` | Blended metric showing how effectively the user base is being monetized overall. |
